KI-Telefonassistent für Arztpraxen · Architektur

Was passiert, wenn eine Patientin in der Praxis anruft

Ein Voice Agent nimmt ab, n8n auf einem eigenen Server erledigt die Arbeit, Google Calendar hält die Termine, und das Praxisteam sieht alles im Dashboard. Wähle einen Ablauf und gehe ihn Schritt für Schritt durch, oder klicke auf einen Baustein.

Sicherheitsgrenzen

  • 1Von außen ist auf der n8n-Adresse nur /webhook/vapi-praxis erreichbar, und nur mit Bearer-Token. Den Editor gibt es nur per SSH-Tunnel.
  • 2Interne Wege (/intern/*, Dashboard-API) laufen nur im Docker-Netz. Caddy antwortet von außen mit 403.
  • 3n8n speichert keine erfolgreichen Ausführungen. Patientendaten bleiben nur im Kalender und bei Rückrufen im Dashboard.
  • 4Der Google-Zugang ist ein Service-Account ohne Projektrollen, mit einem freigegebenen Kalender, zwei Scopes und einer Domain-Freigabeliste.
  • 5Geheimnisse stehen nur in docker/.env auf dem Server (Modus 600), nie im Repo.
  • 6Dashboard: persönliche Logins (scrypt), Sperre nach 5 Fehlversuchen, CSRF-Schutz, strenge CSP.
